Phase 01
The Language of Math — Pre-Calculus
Weeks 1–6

Before calculus, you need to speak math fluently. Functions, graphs, and algebra are the grammar. Skip this and everything after will feel foreign.

Core
Functions & Graphs
A function is a machine: input → output. Everything in ML is a function — your model, your loss, your activation. You need to read graphs like sentences.
Where you'll see this in MLReLU, sigmoid, tanh — these are all functions you'll graph and reason about.
Core
Algebra of Equations
Rearranging equations is how you derive formulas. Backpropagation is just algebra — chain rule applied carefully step by step.
Where you'll see this in MLDeriving the gradient update rule from scratch requires clean algebraic manipulation.
Visual First
Exponential & Log Functions
Logarithms turn multiplication into addition. They tame huge numbers. Understanding why log appears in cross-entropy loss requires this foundation.
Where you'll see this in MLLog-likelihood, cross-entropy loss, softmax — all log-heavy.
Core
Trigonometry Basics
Sine/cosine encode periodicity. Positional encodings in Transformers use sinusoidal functions. You need to know how sin/cos behave visually.
Where you'll see this in MLTransformer positional encodings, Fourier features in neural networks.

Phase 02
Calculus — The Engine of Learning
Weeks 7–18

Calculus is just two big ideas: how fast things change (derivatives) and how things accumulate (integrals). Every gradient descent step you'll ever run is calculus.

Core
Limits & Continuity
Limits answer: "what is the function approaching even if it can't get there?" This is the honest definition of a derivative. Without it, calculus is just tricks with no foundation.
Where you'll see this in MLUnderstanding why learning rate can't be too large — gradient behavior at extremes.
Core
Derivatives — Rate of Change
The derivative tells you the slope at any point. Training a neural network means following the slope downhill (gradient descent) to minimize loss. This IS the derivative.
Where you'll see this in MLGradient descent. Every weight update in every model ever trained.
ML Critical
Chain Rule
The chain rule computes derivatives of composed functions. Backpropagation IS the chain rule applied layer by layer through your network. This is the single most important calculus concept for DL.
Where you'll see this in MLBackpropagation. Automatic differentiation (PyTorch autograd). Every optimizer.
Visual First
Partial Derivatives
When a function has multiple inputs, you differentiate with respect to one at a time. ML models have millions of parameters — each weight gets its own partial derivative (gradient).
Where you'll see this in MLThe gradient ∇L is a vector of all partial derivatives of the loss L.
Core
Gradient & Directional Derivative
The gradient points in the direction of steepest increase. Flip its sign → steepest decrease. That's gradient descent. Visualize a ball rolling down a bowl.
Where you'll see this in MLSGD, Adam, RMSProp — all gradient-based optimizers.
Core
Integrals & Area
Integration is accumulation — summing infinitely many infinitely small pieces. It underpins probability density functions, expected values, and information theory.
Where you'll see this in MLProbability distributions, KL divergence, Bayesian inference, VAEs.
ML Critical
Taylor Series & Approximation
Any smooth function can be approximated locally with a polynomial. Optimizers like Newton's method and second-order methods use this. Loss landscape analysis uses this.
Where you'll see this in MLAdam optimizer derivation, curvature of loss surfaces, Hessian-based analysis.
Visual First
Optimization — Minima & Maxima
Where is the derivative zero? That's where functions reach peaks or valleys. Training = finding the parameter values where loss is at its valley (minimum).
Where you'll see this in MLLoss minimization, saddle points, local vs global minima in training.

Phase 03
Linear Algebra — The Structure of Data
Weeks 14–22

Data is vectors. Transformations are matrices. Neural networks are matrix multiplications stacked with nonlinearities. This phase runs parallel with Phase 2 from week 14 onwards.

Core
Vectors & Vector Spaces
A vector is a list of numbers that represents a point, a direction, or a data sample. Word embeddings are vectors. Images are vectors. Your intuition for high-dimensional space starts here.
Where you'll see this in MLWord2Vec, embeddings, feature representations, cosine similarity.
ML Critical
Matrix Multiplication
Every layer of a neural network is a matrix multiplication. Understanding what the operation does geometrically (stretching, rotating space) gives you deep intuition for why networks work.
Where you'll see this in MLForward pass in every neural network. Attention in Transformers (Q·Kᵀ).
Visual First
Eigenvectors & Eigenvalues
Eigenvectors are directions a matrix doesn't rotate — only stretches. They reveal the true "axes of variation" in data. PCA is entirely built on this concept.
Where you'll see this in MLPCA, covariance matrices, spectral methods, stability of optimization.
Core
Dot Product & Projections
The dot product measures how aligned two vectors are. Attention in Transformers literally computes "how relevant is this query to this key?" using dot products.
Where you'll see this in MLAttention mechanism, cosine similarity, linear regression normal equation.
Core
Matrix Decomposition (SVD)
SVD breaks any matrix into simpler pieces — revealing its true structure. It's how you compress information while preserving what matters most.
Where you'll see this in MLDimensionality reduction, recommendation systems, image compression, LoRA fine-tuning.
Visual First
Norms & Distances
How far apart are two vectors? L1 norm (Manhattan distance) and L2 norm (Euclidean distance) appear everywhere — in loss functions, in regularization, in clustering.
Where you'll see this in MLL1/L2 regularization (Lasso/Ridge), MSE loss, KNN, k-means clustering.
Resources for Phase 3
📺 3Blue1Brown — Essence of Linear Algebra youtube (mandatory) 📖 Introduction to Linear Algebra — Gilbert Strang book 📺 MIT 18.06 — Gilbert Strang lectures OCW free 🛠️ NumPy — implement operations in code python 🛠️ Immersive Math — interactive LA book free online

  • For any ML paper equation: decode each matrix dimension label
Phase 04
Probability & Statistics — The Language of Uncertainty
Weeks 20–30

ML models don't output facts — they output probabilities. Understanding uncertainty, distributions, and statistical reasoning is what separates someone who runs models from someone who understands them.

Core
Probability Fundamentals
What does P(A|B) mean? Conditional probability is the foundation of Bayes' theorem, which is the foundation of Bayesian ML, belief updating, and generative models.
Where you'll see this in MLNaive Bayes, Bayesian networks, posterior distributions in VAEs.
ML Critical
Distributions (Gaussian, Bernoulli, etc.)
A distribution describes all possible outcomes and their likelihoods. The Gaussian is the most important shape in statistics. Neural network outputs are often modeled as distributions.
Where you'll see this in MLOutput layers, noise models, VAE latent space, diffusion model forward process.
Core
Expectation & Variance
Expected value is the average outcome. Variance tells you how spread out outcomes are. Loss functions are expectations over data distributions.
Where you'll see this in MLExpected risk, bias-variance tradeoff, stochastic gradient descent theory.
ML Critical
Maximum Likelihood Estimation
MLE is the answer to: "what parameters make our observed data most probable?" Minimizing cross-entropy loss IS maximizing likelihood. This is why your loss function is what it is.
Where you'll see this in MLEvery classification loss. Logistic regression. Language model training.
Visual First
Information Theory (Entropy, KL Div)
Entropy measures surprise or uncertainty in a distribution. KL divergence measures how different two distributions are. These appear everywhere in modern deep learning.
Where you'll see this in MLCross-entropy loss, VAE ELBO, GANs, knowledge distillation, transformer training.
Core
Bayes' Theorem
Bayes is the math of updating beliefs with evidence. Prior → evidence → posterior. This is the philosophical backbone of probabilistic ML and uncertainty quantification.
Where you'll see this in MLBayesian deep learning, probabilistic models, uncertainty estimation.
Resources for Phase 4
📺 StatQuest with Josh Starmer youtube (best ever) 📖 Think Bayes — Allen Downey free book 📖 Probability Theory — Jaynes free PDF 🛠️ SciPy.stats — simulate distributions python 🛠️ Seeing Theory — visual probability free online

Phase 05
Deep Learning Math — Putting It All Together
Weeks 28–52+

Now the payoff. Every concept you built becomes a tool. You'll read papers, derive equations, and understand why architectural choices are made — not just how to implement them.

ML Critical
Neural Networks from Scratch
Build a net using only NumPy. Write forward pass, compute loss, backprop by hand. This crystallizes everything — calculus, linear algebra, probability — into one working system.
Where you'll see this in MLUnderstanding PyTorch autograd, debugging training, reading architecture papers.
ML Critical
Optimization Theory
Why does Adam work better than SGD? What are saddle points? What is the Hessian and why does curvature matter? This is the difference between tuning hyperparameters blindly vs intelligently.
Where you'll see this in MLSGD, Adam, learning rate schedules, loss landscape analysis.
Core
Convolutions & Signal Math
A convolution is a sliding dot product — measuring local pattern similarity. CNNs work because of this: they detect features (edges, shapes) at any location in an image.
Where you'll see this in MLCNNs for vision, 1D convolutions for text, graph convolutions for GNNs.
ML Critical
Attention Mechanism Math
Attention = soft lookup. The math is Q·Kᵀ/√d → softmax → weighted sum of V. Once you can derive this from linear algebra and probability, Transformers become obvious.
Where you'll see this in MLEvery Transformer, GPT, BERT, ViT, diffusion model using attention.
Visual First
Generative Model Math (VAE, GAN, Diffusion)
VAEs use probability + calculus. GANs use game theory + optimization. Diffusion uses stochastic calculus. These are the frontier — and they're built from everything you've learned.
Where you'll see this in MLStable Diffusion, DALL-E, GPT training, text-to-image research.
Core
Reading Research Papers
The goal of this entire roadmap: you can pick up "Attention Is All You Need" or any landmark paper, read the equations, and understand what's being claimed. This is the finish line.
Where you'll see this in MLStaying current, implementing SOTA, designing novel architectures.

Your Learning Tracker System

// How to track progress without overwhelm

The Feynman Test

After every topic: explain it to an imaginary 12-year-old with no jargon. If you can't, you don't know it yet. Write it in a notebook.

Notion / Obsidian

One page per concept. Sections: What is it → Why it exists → ML connection → My intuition in plain English → Code example.

Spaced Repetition

Use Anki for formulas and definitions. Don't memorize — test. Create a card for each: "What does the gradient point toward?"

Monthly Review

On the 1st of each month: revisit Phase 1 exercises. Can you still do them cold? Retention is everything. Revise the weak spots.

Struggle Log

Keep a "stuck" log. When something doesn't click, write it down. Return to it in 3 days with fresh eyes. Most confusion resolves.

Progress Milestone

Phase complete = implement one ML concept using that phase's math from scratch. No libraries. If it runs: phase is unlocked.

The Principles That Make This Stick

1

Why before How

Never learn a formula before understanding the problem it solves. "Why does the chain rule exist?" before "how do I apply it?"

2

Plot Everything

If you can't draw it, you don't own it. Every new function, equation, or transformation gets graphed before it gets used.

3

ML Connection Rule

For every math concept learned: find one real ML application before moving on. This bridges theory to intuition permanently.

4

Implement or it Didn't Happen

Reading ≠ understanding. Code a neural net, code gradient descent, code attention. Your fingers need to know what your brain knows.

5

Slow = Fast

One concept fully understood beats five concepts half-learned. You will not revise Phase 1 if you master it once. Don't rush the foundation.

6

Confusion is Progress

The feeling of "this doesn't make sense" is exactly when you're learning. Log it. Sleep on it. Return to it. Confusion ≠ failure.
